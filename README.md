Student Management System

Project Overview

The Student Management System is a Python-based application designed to manage student records and leave applications. It uses JSON files to store and retrieve information.

Features

- Admin login authentication
- Add new student records
- View all student details
- Search students by ID
- Delete student records
- Apply for leave
- View leave applications
- Approve leave requests
- Reject leave requests

Technologies Used

- Python
- JSON
- Visual Studio Code
- Git and GitHub

Project Structure

- "main.py" – Main program and menu navigation
- "student.py" – Student record management
- "leave.py" – Leave management
- "login.py" – Admin login
- "student.json" – Student data storage (local)
- "leave.json" – Leave data storage (local)
- "user.json" – User credentials (local)

How to Run

1. Install Python.
2. Clone or download this repository.
3. Open the project folder in VS Code.
4. Run the following command:

python main.py

Learning Outcomes

- Python functions and modules
- Lists and dictionaries
- File handling
- JSON data management
- Conditional statements and loops
- Git and GitHub version control
